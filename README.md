# REBOOT 

REBOOT는 은둔·고립 청년의 규칙적인 생활 습관 형성과 일상 회복을 지원하기 위해 개발한 AI 기반 모바일 애플리케이션입니다.

AI 동작인식 기술을 활용해 사용자의 행동을 자동으로 인식하고, 미션 수행 여부를 판정하여 실시간 피드백을 제공합니다. 또한 생활 루틴 관리, 성취도 리포트, 일기 및 커뮤니티 기능을 통해 지속적인 습관 형성을 지원합니다.

프로젝트에서 React Native 기반 클라이언트, Node.js·Express 서버, MariaDB 데이터베이스 개발 및 AI 모델 연동을 담당했습니다. 특히 개발 환경별 DB 불일치와 앱-서버 통신 오류를 직접 해결하며 안정적인 서비스 연동 환경을 구축했습니다.
